# 🔮 Personality Plus: DISCOVER YOUR TRUE SELF

Aplikasi web interaktif untuk mengetahui kecenderungan 4 tipe temperamen kepribadian (**Sanguinis, Koleris, Melankolis, Plegmatis**) berdasarkan buku *Personality Plus* karya Florence Littauer.

## ✨ Fitur Utama
* **Multi-Page Flow:** Terdiri dari 4 halaman terpisah (*Landing Page*, *Weaknesses*, *Strengths*, dan *Result*).
* **Smart Scoring & Combination:** Mampu mendeteksi tipe kepribadian tunggal maupun kombinasi dua temperamen dominan.
* **Psychological Insights:** Memberikan penjelasan mendalam mengenai karakter, kekuatan (*strengths*), dan tantangan (*challenges*).

## 🛠️ Teknologi yang Digunakan
* **Backend:** Python & Flask (menerapkan konsep *Object-Oriented Programming* / OOP dengan pilar *Inheritance*).
* **Frontend:** HTML5 & Custom CSS3.
* **Deployment:** PythonAnywhere.

*Catatan: Aplikasi ini dibuat untuk tujuan edukasi pemrograman dan hiburan.*
